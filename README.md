# An Online Quiz System

An online quiz system to practice JavaScript backend using Node.Js, Express, EJS, MongoDB, HTTPS, Helmet, Crypto, and bcryptjs

## Features Brief

Below is a brief list of the features; however you can still learn more by reading the [wiki](https://github.com/TheFujirose/online-quiz-system/wiki).

* Account login, registration, and sign-out.
* Regular users to take quiz and view quiz analytics.
* Administrators to create, edit, quizzes and questions
* Automatic semantic versioning for quizzes

## Technology

* **Frontend**: EJS
* **Backend**: NodeJs with Express
* **Database**: MongoDB
